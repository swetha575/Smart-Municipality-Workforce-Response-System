## Smart Municipality Workforce Response System

## 📌 Overview

The Smart Municipality Workforce Response System is a Flask-based web application developed to streamline municipal operations and improve service efficiency. The system helps manage complaints, workforce allocation, attendance tracking, task assignment, food distribution, and administrative activities through a centralized platform.

---

## 🚀 Features

* Complaint Management System
* Attendance Tracking
* Task Assignment and Monitoring
* Food Distribution Module
* User Authentication and Authorization
* Admin Dashboard
* Database Management
* Machine Learning Model Integration using ONNX
* Responsive User Interface

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/Smart-Municipality-Workforce-Response-System.git
```

### Navigate to the project directory

```bash
cd Smart-Municipality-Workforce-Response-System
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python run.py
```
